## 2026-10-09 (cont.) — info panel and 3D callouts

(`~/Desktop/MuscleAtlas-layout-demos/`, scratch copy outside the repo); owner chose A (floating panels) with a slim

**Learned:** The first geometry code allocated Vector3s per triangle: 20-400 ms per muscle and idle-frame hitches up to

mirror correction (`sign(det(matrixWorld))`) is proven by a mutation test (remove it, two tests fail). A second
independent review found regressions introduced by the first review's fixes (dropped "volume-equated", dangling
"same study"): re-review changed entries every time.
**Left:** UI uncommitted; anchors rewrite in flight (agent a86106f). 8 local commits unpushed.
